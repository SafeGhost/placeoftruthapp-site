# placeoftruthapp.com: концепция сайта

Источник: промпты 1–7 из треда, присланные 19.11.2026.

## 1. Визуальное направление: «Ночь в храме»
Посетитель входит ночью в египетский храм. Вокруг тьма, тёплое золото и лазурит, по воздуху плывёт пыль в свете лампы.
- Палитра: почти чёрный с коричневым (#0d0a07), золото (#d9b15c, #f3d58a), папирус (#f1e3c2), глубокий лазурит (#22356e) для редких акцентов.
- Шрифты: Cormorant SC для заголовков (как резьба по камню), Cormorant Garamond для текста. Без шрифтов «из шаблона».
- Свет: тёплый ключевой свет сверху слева, холодный лунный контровой свет справа. Золото бликует.
- Камера: медленные проезды без резких движений, как в документальном кино.
- Атмосфера: спокойная красота и лёгкая тайна, без жути (правило Place of Truth).

## 2. Путь посетителя и цель каждого блока
1. Первый экран. В воздухе висит 3D-амулет Уджат (Око Гора), за ним ночной Нил. Сразу понятно, что это за приложение. Цель: удержать и показать уровень.
2. Легенда. Что такое Место Истины. Цель: дать смысл и историю.
3. Пять обрядов. Телефон закреплён на экране, при прокрутке в нём сменяются экраны приложения. Цель: показать, что внутри.
4. Ларец амулетов. Три амулета в 3D, их можно крутить пальцем. Цель: вызвать «вау» и желание собрать все.
5. «Что тебе снилось?» Живой поиск по 789 снам. Цель: полезное действие сразу и вход в сонник.
6. Храм хранит тайны: без аккаунта, без рекламы, 9 языков. Цель: снять страхи.
7. Бесплатно и полная версия. Цель: честно сказать про деньги.
8. Финальный экран со сфинксом и кнопкой. Цель: установка.

## 3. Первый экран
- Центральный объект: золотой Уджат из наших 3D-моделей, чуть наклонён, медленно вращается.
- Реакция: на компьютере амулет поворачивается вслед за курсором, на телефоне — при наклоне телефона. При прокрутке амулет поворачивается и уходит вглубь, текст гаснет.
- Вокруг амулета летают золотые пылинки.
- Текст слева внизу, крупный: «Place of Truth» и одна строка о том, что это. Ценность понятна за 3 секунды.

## 4. Движение
- Появление блоков: подъём на 24 px и проявление, плавность cubic-bezier(.2,.7,.2,1), 0.9 с.
- Параллакс пейзажей: фон движется медленнее текста.
- Закреплённый телефон в «Пяти обрядах»: экраны сменяются наплывом.
- При настройке «уменьшить движение» вся анимация выключается, 3D стоит неподвижно.

## 5. Сборка
- Чистый HTML, CSS и JS без сборщиков. 3D на three.js из CDN, грузится после первого показа страницы.
- Страницы сонника остаются лёгкими: без 3D, чтобы Google их быстро открывал и ставил выше.
- Хостинг GitHub Pages, адрес placeoftruthapp.com.
